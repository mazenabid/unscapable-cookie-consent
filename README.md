# 🍪 Unscapable Cookie Consent

Ever clicked **"Reject All"** and somehow ended up in 14 different settings menus?

Yeah... this is that.

Unscapable Cookie Consent is a small web project that pokes fun at the never-ending cookie banners and preference screens we encounter across the internet.

## Features

- 🍪 Cookie banners
- Javascript skills on mouse hovering effects
- Java script setTimeOut usage
- Disabling the "x" button
- stealing your name and making fun of you

## Why?

Because some websites make rejecting cookies feel like a side quest.

This project exaggerates that experience into something slightly ridiculous, but perhaps not *that* ridiculous.
